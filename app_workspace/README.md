# app_workspace

The actual Android project lives here. It does **not** exist until `G2` runs:

```bash
.agents/skills/02-android-scaffold/scripts/scaffold_project.sh
```

Generated by the official Android CLI template (`android create`), then
post-processed by the pipeline (SDK path, `.gitignore`, Gradle defaults, root
project name). Expected layout after scaffolding:

```
app_workspace/
├── app/                        # application module (entry point, navigation host)
├── gradle/
│   ├── libs.versions.toml      # single source of versions
│   └── wrapper/
├── build.gradle.kts
├── settings.gradle.kts
├── gradle.properties
├── gradlew
├── local.properties            # generated, never committed
└── .pipeline/                  # pipeline state, not part of the app
    ├── spec.json               # G1 output
    ├── plan.md                 # G1 output
    ├── STATE.json              # current gate and next action
    ├── reports/                # evidence: verify-*, device-*, quality-*
    └── artifacts/              # screenshots, previews, logs
```

Rules:

- Don't commit `build/`, `local.properties`, keystores, or `.pipeline/reports/`.
- Versions only change in `gradle/libs.versions.toml` (and then
  `00_memory/TECH_STACK.md` in the same change).
- The gate is the build: a project that generates but does not compile leaves
  `G2` open.
