# Tech stack

> Single source of truth for versions. It **must** match
> `app_workspace/gradle/libs.versions.toml`. A mismatch is a defect: fix both in
> the same change. Policy: exact pins, no ranges, upgrades are gated changes.

Verified: `2026-11-08` · source: official `android create` template + Google
Maven + Maven Central.

> The CLI template varies with the installed bundle: the one resolved here ships
> `compileSdk 37` while AGP 9.0.1 documents a ceiling of 36.1. `spec.json` is the
> source of truth — `scaffold_project.sh` applies its `minSdk`/`compileSdk`/
> `targetSdk` to the generated project, so the table below wins over the template.

## Forbidden / deprecated

- `org.jetbrains.kotlin.android` (AGP 9 built-in Kotlin), `kotlin-kapt`.
- `com.android.compose.screenshot` standalone plugin → AGP test suites.
- `proguard-android.txt` → `proguard-android-optimize.txt`.
- Version ranges (`1.2.+`), dynamic versions, snapshot/beta in `release`.

## Upgrade policy

1. Check availability (`android studio version-lookup`, Maven metadata).
2. Bump in `libs.versions.toml` only.
3. `05-build-test-loop` green → screenshot comparison → device smoke.
4. Append `DL`, update this file and `docs/PIPELINE.md` if the baseline moved.
